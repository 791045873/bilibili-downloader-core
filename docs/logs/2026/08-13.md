# Development Log - 2026-08-13

### Vision Proxy 代理路径自动重试（`docs/plans/2026-08-13-vision-proxy-retry-plan.md`，已关闭）

- 来源：用户报告 `LLM 多模态代理调用失败 (status=500...): ('Connection aborted.', ConnectionResetError(10054, ...))`。根因：dashscope SDK 向阿里云 OSS 上传/推理时连接被重置（10054），代理 `except Exception` 返回 500（body 为 Python 错误文本），Node 代理路径无重试，一次瞬时失败整单失败。
- 实现（`packages/adapters/src/llm/qwen-client.ts`）：`multimodalChat` 代理路径改为最多 2 次尝试（`VISION_PROXY_MAX_ATTEMPTS = 2`，失败间隔 `VISION_PROXY_RETRY_DELAY_MS = 2000`）；fetch 网络错误（非 AbortError）与代理 500/502/503 重试 1 次；超时（AbortError）与 4xx/解析错误立即抛错不重试；成功路径仅调用 1 次；最终错误信息格式与现状一致。
- 决策：固定常量（不新增 env），重试 5xx 以覆盖"代理包装 DashScope 瞬时 500"的主故障路径；重试一次最多双倍推理调用成本（按内容幂等），裁定可接受。
- 验证：`pnpm typecheck`、`pnpm build` 通过；运行级 stub 冒烟 6/6 PASS（[500,200]→成功 2 次调用、[500,500]→报错 2 次、连接重置后→成功 2 次、挂起→超时不重试 1 次、413→不重试 1 次、200→仅 1 次）。
- 文档：架构基线健壮性不变量补充重试说明；审计文件见 `docs/audits/2026-08-13-plan-audit-vision-proxy-retry.md`（passed）与 `docs/audits/2026-08-13-closure-audit-vision-proxy-retry.md`（闭核算）。
