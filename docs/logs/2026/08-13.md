# Development Log - 2026-08-13

### Vision Proxy 代理路径自动重试（`docs/plans/2026-08-13-vision-proxy-retry-plan.md`，已关闭）

- 来源：用户报告 `LLM 多模态代理调用失败 (status=500...): ('Connection aborted.', ConnectionResetError(10054, ...))`。根因：dashscope SDK 向阿里云 OSS 上传/推理时连接被重置（10054），代理 `except Exception` 返回 500（body 为 Python 错误文本），Node 代理路径无重试，一次瞬时失败整单失败。
- 实现（`packages/adapters/src/llm/qwen-client.ts`）：`multimodalChat` 代理路径改为最多 2 次尝试（`VISION_PROXY_MAX_ATTEMPTS = 2`，失败间隔 `VISION_PROXY_RETRY_DELAY_MS = 2000`）；fetch 网络错误（非 AbortError）与代理 500/502/503 重试 1 次；超时（AbortError）与 4xx/解析错误立即抛错不重试；成功路径仅调用 1 次；最终错误信息格式与现状一致。
- 决策：固定常量（不新增 env），重试 5xx 以覆盖"代理包装 DashScope 瞬时 500"的主故障路径；重试一次最多双倍推理调用成本（按内容幂等），裁定可接受。
- 验证：`pnpm typecheck`、`pnpm build` 通过；运行级 stub 冒烟 6/6 PASS（[500,200]→成功 2 次调用、[500,500]→报错 2 次、连接重置后→成功 2 次、挂起→超时不重试 1 次、413→不重试 1 次、200→仅 1 次）。
- 文档：架构基线健壮性不变量补充重试说明；审计文件见 `docs/audits/2026-08-13-plan-audit-vision-proxy-retry.md`（passed）与 `docs/audits/2026-08-13-closure-audit-vision-proxy-retry.md`（闭核算）。

### 生产环境文件日志（`docs/plans/2026-08-13-production-file-logging-plan.md`，已关闭）

- 来源：用户需求——Node 与 Python 服务日志除终端外，生产环境运行时进入对应日志文件。
- 实现：
  - Node：新增 `packages/server/src/logging/file-logger.ts`（`FileConsoleLogger extends ConsoleLogger`，先 `super.*()` 保留终端，再写文件）；`main.ts` 用 `app.useLogger(new FileConsoleLogger())`（不加 `bufferLogs`，避免异步 listen 失败时缓冲日志不 flush）；`rotating-file-stream` 按天轮转，活动文件 `server-YYYY-MM-DD.log`。
  - Python：`qwen_vision_proxy.py` 新增 `configure_file_logging()`，`LOG_DIR` 存在时 `mkdir` + `TimedRotatingFileHandler`（`when="midnight"`，活动文件 `vision-proxy.log`，轮转出 `vision-proxy.log.YYYY-MM-DD`）。
  - Docker：`Dockerfile` 增加 `ENV LOG_DIR=/download/logs` + `RUN mkdir -p /download/logs`。
- 决策：`LOG_DIR` 显式开关（未设置行为不变）；文件日志全量与终端一致；Node 用库 `rotating-file-stream`、Python 用标准库；`LOG_MAX_FILES` 默认 7。
- 验证：`pnpm typecheck`、`pnpm build`、venv `python -m py_compile` 均通过；运行级冒烟：Node 生成 `server-2026-08-13.log`（启动/请求/WARN/ERROR+stack）、Python 生成 `vision-proxy.log`（启动横幅/请求行/异常 traceback）、未设 `LOG_DIR` 无文件生成、4 组密钥均未进日志；`docker:build` 因既有 ffmpeg 基础镜像问题本机受阻（与本次改动无关，详见 testing 文档方向 6 裁定）。
- 文档：`docs/context/codebase-map.md`、`docs/architecture/2026-07-06-video-analysis-baseline.md`、`docs/design/app-overview.md` 对齐；审计文件 `docs/audits/2026-08-13-plan-audit-production-file-logging.md`（首轮 needs revision → 修订 B1/B2/B3 → 复核 approved）与 `docs/audits/2026-08-13-closure-audit-production-file-logging.md`（闭核算 approved）。
