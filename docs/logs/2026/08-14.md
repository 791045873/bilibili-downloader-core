# Development Log - 2026-08-14

### 前端技术栈迁移：Vue 3 → React 19（`docs/plans/2026-08-14-frontend-react-migration-plan.md`，已关闭）

- 来源：用户直接需求——`packages/frontend` 由 Vue 技术栈改造为 React 19 + TypeScript + Zustand + antd，其余技术选型按社区最佳实践，全程自主执行并本地提交、推送远程。
- 选型（npm registry 2026-08-14 核验）：React 19.2.8 + react-router 7.18.2（library 模式，createBrowserRouter + lazy）+ Zustand 5（客户端状态，persist 持久化）+ TanStack Query 5（服务端状态）+ antd 6.6.0（组件库，含内置 QRCode）+ Tailwind 4（保留布局工具类）+ Vite 8 + TS 5.9（与工作区 ^5.7.0 同线）。
- 实现：
  - `package.json`/`tsconfig.json`/`vite.config.ts`/`index.html`/`env.d.ts` 替换；`views/*.vue` 删除，`src/pages/*.tsx` 8 页面同构重写；路由路径、localStorage key（`bilibili-downloader-settings`/`bilibili-downloader-task-ids`）、API 契约全部保持。
  - 3 个 zustand store：`settings`（persist）、`downloadQueue`（persist）、`auth`（QR 轮询，2s 间隔语义保留）。页面数据层用 TanStack Query（列表/详情/轮询），任务轮询改为 TaskRow 按行 `refetchInterval` 非终态 3s、终态停止。
  - antd v6 适配：size 用 `small`/`medium`（不用 `middle`）、Select 用 `variant` 体系、按钮用 `color`+`variant`、主题 token `colorPrimary:#f43f5e` 对齐原玫瑰红品牌色、zh_CN locale + dayjs。
- 关键修复（测试驱动发现）：
  1. **旧数据迁移**：Pinia 版存裸 JSON，zustand persist 存 `{state,version}` 信封——直接替换会把既有用户设置/队列 ID 静默重置。两 store 模块加载时 `migrateLegacyStorage()` 一次性识别并转写旧格式。
  2. **显式 merge**：persist 默认 merge 是顶层替换，settings 会丢失存储中不存在的默认字段——两 store 补 `merge` 字段级合并（Node mock localStorage 实测断言通过）。
- 验证：`pnpm --filter @bilibili-downloader/frontend typecheck`、`pnpm build`、全仓 `pnpm typecheck` 通过；`vite preview` 冒烟（`/`、SPA 深链、主 bundle 均 200）；`dist` 无 vue 残留；store 迁移 + rehydrate Node 实测全部断言通过。运行级 UI 交互（浏览器）留用户手动验证（见 `docs/testing/2026/08-14-frontend-react-migration-testing.md`）。
