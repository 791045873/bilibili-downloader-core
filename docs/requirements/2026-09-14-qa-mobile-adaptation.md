# 需求：QA 穿搭问答页移动端适配（含共享顶栏壳层）

> 来源：用户 2026-09-14 直接请求（"系统分析 qa 前端页面，准备做移动端适配改造"）+ 现状扫描结论
> Owner Doc：`docs/design/app-overview.md`（穿搭问答（Web）章节）
> 相关既有实现：`docs/requirements/2026-09-09-rag-chat-service.md`（QA 页功能基线）
> 范围确认（2026-09-14，用户）：QA 页 + 共享顶栏壳层；窄屏会话列表面板采用 Drawer 抽屉

## Goal

让 `/qa` 穿搭问答页在手机浏览器（竖屏约 360–430px 宽）上可用、可读、可输入，且不因共享顶栏导航溢出而无法进入；桌面端（≥768px）保持现有双栏体验不变（助手回复示例图形态除外，两端统一更新）。

## In Scope

### 全局基线

- `packages/frontend/index.html` 视口配置补齐移动端所需能力（安全区适配 `viewport-fit=cover`、虚拟键盘交互模式 `interactive-widget=resizes-content`、品牌 `theme-color` = `#f43f5e`）。
- 全局样式补充移动端所需的高度与安全区基础能力（动态视口高度、`env(safe-area-inset-*)`）。
- 顶栏实际高度以测量值（含顶部安全区）暴露为壳层变量，供需要底部锚定的页面消费，不写死 `3.5rem`。

### 共享 App 顶栏壳层（`packages/frontend/src/App.tsx`）

- 窄屏（`< 768px`）将 logo + 导航项 + 登录入口折叠为汉堡菜单 + 抽屉，顶栏保持固定高度不换行。
- 桌面端（`≥ 768px`）顶栏与导航维持现状（横向排布）。
- QA 页在移动端有稳定可用的内容高度，底部输入区不因浏览器地址栏/软键盘而被遮挡。
- 其他全宽页面（`/downloading`、`/summary-tasks`）保持现有文档级滚动，不因壳层改动出现布局或滚动回归。

### QA 页（`packages/frontend/src/pages/QaChat.tsx`）

- 窄屏改为单列：会话列表以 Drawer 抽屉呈现，聊天区占满宽度；提供明确的"会话列表"入口，选中会话后抽屉自动关闭。
- 桌面端保持现有左侧固定会话列表 + 右侧聊天区双栏布局。
- 聊天滚动区与底部输入区适配动态视口高度、软键盘与安全区；滚动只发生在消息容器内，不整页跳动。
- 输入区在窄屏下紧凑化（照片/发送控件改为图标形态并保证可点按），文本域可用宽度不被按钮过度挤压。
- 消息气泡、用户照片、回复图片与视频来源在窄屏下自适应宽度且不横向溢出。
- 助手回复的示例图（`replyImages`）改为**横向并排缩略图条**（桌面与移动端采用同一形态）：缩略图本身不显示文字；点击任一张进入全屏查看器，可**左右滑动**或使用内置左右按钮/键盘方向键切换同一条回答内的全部示例图，全屏时展示该图对应的技巧标题（`tipTitle`）与说明（`caption`）。
- 会话删除等交互控件在触屏下有足够触控目标并有二次确认。
- 空态、加载态、发送中、失败可重试等既有状态在移动端保持可用。

## Out Of Scope

- 下载队列、AI 总结任务、设置、提示词管理等**其他页面的内容布局重设计**（本次仅保证共享顶栏壳层改动后它们不回归、仍可正常打开）。
- PWA/离线/安装/Service Worker、原生 App 或 Capacitor 封装。
- 后端、API 契约、数据库/模型、鉴权、部署的任何改动。
- 回答形态（非流式）、三段式结构、照片上传语义的改动。
- 桌面端布局/顶栏视觉重设计（助手回复示例图形态调整除外）。
- 引入第三方手势/轮播库（如 swiper）；左右滑动在现有能力内自行实现，不新增依赖。

## Main User Flows

### 移动端进入 QA 页

1. 用户在窄屏打开站点，顶栏只显示品牌与汉堡按钮。
2. 点汉堡展开抽屉，选择"穿搭问答" → 抽屉关闭并导航到 `/qa`。
3. QA 页默认展示当前（最近）会话的聊天内容；用户可点"会话列表"抽屉切换到其他会话或新建会话。

### 移动端文本问答

1. 用户在输入区输入问题，点发送（窄屏下回车不直接发送）。
2. 回答三段式渲染：正文 + 图片示例 + 视频注脚；长内容只在消息区内滚动。

### 移动端照片问答

1. 用户点照片按钮从相册/相机选择 ≤3 张图片，预览 chip 换行展示。
2. 发送后用户消息与助手回答正常显示，图片按屏幕宽度自适应。

### 移动端查看回复示例图

1. 助手回答返回后，示例图以横向缩略图条展示（无标题文字）。
2. 用户点击任一张缩略图 → 全屏查看大图，并显示该图的技巧标题与说明。
3. 全屏下左右滑动（或用内置左右按钮/键盘方向键）切换同一条回答内的其余示例图；关闭后回到聊天位置。

### 移动端会话管理

1. 打开会话列表抽屉 → 选择会话回看并继续；或新建会话。
2. 删除会话需二次确认，触屏可准确点按。

## Business Rules

- **断点单一来源**：布局在桌面/移动之间切换的判定统一为 `768px`（antd `md`）；Tailwind 断点仅用于样式，不另立阈值。
- **桌面优先不变**：`≥ 768px` 下 QA 页布局与顶栏行为与改造前一致（助手回复示例图形态除外，两端统一按"回复示例图查看"规则更新）。
- **窄屏单列 + 抽屉**：`< 768px` 下 QA 页为单列，会话列表进入 Drawer；Drawer 点击会话、遮罩、关闭按钮均可关闭；当前选中会话在列表中高亮。
- **顶栏高度稳定**：窄屏顶栏折叠后高度保持稳定（不因导航项换行而改变；实际高度随顶部安全区变化，由实测值暴露给消费方），保证 QA 页高度计算稳定。
- **高度模型**：聊天容器高度 = 动态视口高度 − 顶栏实测高度（含顶部安全区）− `main` 垂直内边距（`py-6`，上下共 3rem，与宽度无关）− 底部安全区，避免沿用 `100vh`/`7.5rem` 魔数；仅消息容器内部滚动。
- **软键盘策略**：以动态视口高度为基础；Android 依赖 `interactive-widget=resizes-content` 与动态视口单位；iOS Safari 以 `visualViewport` 尺寸/位移事件调整容器可视高度。验收以"键盘弹收后输入区可见可操作"为准，不承诺两端像素级一致。
- **其他全宽页滚动**：不切换到壳层固定高度，保留文档级滚动，仅消费顶栏变量者需显式声明。
- **安全区**：底部输入区与顶栏避让设备安全区（刘海/Home 指示条）。
- **触控目标**：主要可点按控件（发送、照片、会话列表入口、删除确认）在触屏下有效点击区域不小于约 44px。
- **回车语义**：指针为粗粒度（触屏）时回车换行、发送走按钮；细粒度（鼠标）保持回车发送、Shift+回车换行。
- **回复示例图查看（横向缩略图条 + 全屏查看器）**：同一条助手回答内的示例图以横向并排缩略图展示，超出宽度换行；缩略图不展示 `tipTitle`/`caption`。点击缩略图进入全屏查看器；切换方式为**左右滑动手势**或内置左右按钮/键盘方向键，三种方式等效；全屏态展示当前图的 `tipTitle` 与 `caption`。单张示例图时无左右切换/滑动。缩略图与全屏加载失败均保留占位降级，不影响文本与视频来源展示。该形态在桌面与移动端一致；桌面端其余布局与顶栏不变。
- **滑动与缩放手势仲裁**：当图片处于放大（`scale > 1`）状态时，横向拖动用于平移查看图片，不触发切换；仅在未放大状态下的横向滑动触发上一张/下一张。首张左滑、末张右滑不循环。
- **功能等价**：手机端具备桌面端全部 QA 能力（新建/切换/删除会话、文本问答、照片问答、三段式渲染、来源跳转、空/载/错态），不新增也不删减功能。
- **无后端影响**：不新增/修改任何 API、数据模型或配置。

## Roles / Permissions

- 单用户工具，无角色/权限系统；本次不触碰鉴权（属保护区域，未涉及）。

## Edge Cases

- 横竖屏切换后布局与高度正确。
- 软键盘弹收（iOS 覆盖式、Android 缩放式）后输入区可见、消息不丢失。
- 带安全区设备（刘海屏/手势条）底部与顶部不被遮挡。
- 系统大字体放大后文本不溢出、控件不重叠。
- 超长单词/URL/未换行内容不撑破气泡导致横向滚动。
- 会话数量多时抽屉列表可滚动定位。
- 照片达到上限（3 张）时按钮禁用且状态可见。
- 回复图片加载失败时保留占位降级。
- 回复示例图仅 1 张时，全屏查看无左右切换控件或切换无效果（不出现空控件）。
- 回复示例图较多时，缩略图条换行且可逐张全屏左右切换，切换不越界、不串到其他回答的图片。
- 全屏查看器打开/关闭、左右滑动、按钮/键盘切换在触屏与安全区设备下正常，不影响输入区。
- 滑动方向与切换方向一致（左滑下一张、右滑上一张），且首张不能左滑、末张不能右滑（不循环）；方向不反、不越界。
- 放大状态下横向拖动为平移查看，不触发切换；未放大时横向滑动才切换（滑动与缩放手势不互相误触）。
- 轻微/斜向滑动（低于阈值或纵向为主）不误切图片。
- 仅有图片无文字、或仅有文字无图片的消息均正常展示。
- 新增会话后列表即时更新且抽屉行为正确。
