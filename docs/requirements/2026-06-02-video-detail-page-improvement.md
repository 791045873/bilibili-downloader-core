# Feature: 视频解析页面优化

## Goal

优化"哔哩哔哩下载器"前端视频解析页面的选择、解析、入队和目录确认体验，使用户能更高效地处理视频，并避免重复加入下载队列。

目标组件：`packages/frontend/src/views/VideoDetail.vue`

## In Scope

- 新增 section 选择器模块：以胶囊按钮形式一次性展示所有 section，用户点击选中一个 section 后，页面仅显示该 section 下的内容。
- 调整视频表格第一列 header 文案，使其准确表达该列用途。
- 点击"加入下载队列"后停留在当前视频解析页面，不自动跳转到下载队列页面。
- 已加入下载队列的视频不能再次被选中，避免重复下载同一视频。
- 将"解析选中"调整为"解析当前页所有视频"，并支持一键解析当前页全部视频。
- 当用户点击"加入下载队列"时，弹出目录确认/修改弹框（当前选中的 section 内所有视频都属于同一 section，不再存在跨 section 场景）。
- 在目录确认弹框中允许用户修改本次下载视频的存储目录。
- 目录确认弹框不允许空目录：前端校验阻止提交，后端校验阻止创建。
- 新增后端接口（或在现有接口上扩展），用于按 `bvid + cid` 查询视频任务是否已存在于数据库中，支撑前端"已入队"去重逻辑。
- 后端加入下载队列接口需校验目录非空，拒绝空目录的创建请求。

## Out Of Scope

- 不修改 Core 下载逻辑。
- 不修改 CLI 界面。
- 不修改 Docker 部署。
- 不新增跨页面下载管理能力。
- 不重新设计整个 Web UI。
- 不处理旧版 `docs/requirements/2026-06-02-ui-improvement.md` 中已废弃的泛 UI 优化范围。
- 已入队判定不考虑"同一视频不同画质/编码"的去重，仅以 `bvid + cid` 为唯一标识。

## Main User Flows

1. 用户进入视频解析页面 → 页面加载视频信息 → 展示 section 选择器（胶囊按钮），默认选中第一个 section → 显示该 section 下的视频表格。
2. 用户点击 section 选择器中的不同胶囊按钮 → 切换到对应 section，显示该 section 下的内容。
3. 用户查看视频表格 → 第一列 header 能准确说明该列的选择用途。
4. 用户点击"解析当前页所有视频" → 当前选中 section 内所有可解析视频被解析出画质/编码等信息。
5. 用户选择若干未入队视频 → 点击"加入下载队列" → 弹出目录确认/修改弹框 → 用户确认后加入下载队列 → 页面停留在当前视频解析页。
6. 已加入下载队列的视频在当前页面不可再次选中。

## Business Rules

- 同一份视频以 `bvid + cid` 作为唯一性标识，不应重复加入下载队列。
- "已加入下载队列"的判定规则：
  1. 查询数据库中是否已存在该 `bvid + cid` 的下载任务。
  2. 若存在，且任务状态为"已完成"且创建时间早于当前时间 24 小时以上 → 允许创建新任务。
  3. 否则 → 该视频视为"已入队"，前端禁止选中。
- "解析当前页所有视频"应作用于当前选中 section 内所有尚未解析且可解析的视频，不依赖用户先全选。
- 加入下载队列后应保留当前页面上下文，不自动跳转到 `/downloading`。
- 由于 section 选择器保证每次只展示一个 section 的内容，所有选中的视频必然属于同一 section，目录确认弹框每次都会触发。
- 目录弹框修改的存储目录仅影响本次加入队列操作。
- section 选择器以胶囊按钮形式一次性展示所有 section，按原有 section 顺序依次排列。
- 目录不得为空：前端校验不通过时阻止提交；后端在创建任务时也需校验并拒绝空目录请求。
- 当视频无合集（ugcSeason 为空）时，不显示 section 选择器，直接展示默认合集正文。

## Roles / Permissions

- 无角色区分（单用户工具，不涉及权限变更）。

## Data / Model Impact

- 不要求数据库模型变更（复用现有下载任务表）。
- 需要后端提供按 `bvid + cid` 查询任务状态的接口，以支持前台"已入队"判定和 24 小时已完成任务的复用规则。

## API / Integration Impact

- 需要新增或扩展后端接口：按 `bvid + cid` 批量查询下载任务是否存在及其状态、创建时间，供前端判定哪些视频不可再次选中。
- `createDownload` 接口需新增校验：拒绝 `outputPath` 为空的请求。
- 前端下载队列 store 需与上述后端接口集成，替代仅限前端会话的"已入队"判定。
- 如果现有 `createDownload` 的 `outputPath` 入参已满足目录传递需求，优先复用；否则后续计划必须记录 API 影响并更新 owner doc。

## States

- 加载态：页面正在获取视频信息。
- section 选择态：section 选择器中胶囊按钮展示所有 section，当前选中的 section 高亮。
- 解析中：用户点击"解析当前页所有视频"后，按钮显示处理中且避免重复触发。
- 已解析：视频行展示可选画质/编码信息。
- 未解析：视频行提示待解析或尚无画质信息。
- 已入队：视频行不可选，并有明确视觉提示。
- 目录确认：用户点击"加入下载队列"时展示目录确认/修改弹框。
- 错误态：解析失败或加入队列失败时留在当前页面并展示错误信息。
