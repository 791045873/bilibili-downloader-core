## Testing Directions

### TD-P0-1：同标题不同视频生成不同文件

- 应为真（observable）：两个标题相同但 bvid/cid 不同的视频，在同一 outputPath 下下载完成后，下载列表展示的两个 `outputFile` 路径不同，落盘为两个文件，文件内容分别对应该视频。
- 不应为真（forbidden）：第二个视频被"文件已存在"跳过且落盘为第一个视频的文件。

### TD-P0-2：同一视频重复入队仍幂等跳过

- 应为真：同一 bvid+cid 的视频第二次入队下载时，文件名与第一次完全一致，命中现有"文件已存在, 跳过下载"逻辑，任务返回成功且不产生第二个文件。
- 不应为真：第二次下载覆盖第一次文件，或产生重复文件。

### TD-P0-3：文件名包含实际清晰度

- 应为真：文件名包含 `-q{实际选中的 quality}`（例如 `-q80`），且该 quality 与任务实际选择的视频流一致（用户未指定画质时取最佳流的真实值，而非空）。
- 不应为真：quality 字段缺失、为默认值时拼成空，或使用用户请求值但实际选中流不同（如请求 1080p 但仅 720p 可用）。

### TD-P0-4：字幕文件命名跟随主文件名

- 应为真：下载字幕时，`{langKey}.srt` 与主 mp4 同名派生（如 `标题-bv-cid-q80.zh-CN.srt`），可被分析与用户识别。
- 不应为真：srt 与主文件命名脱节，指向旧命名格式。

### TD-P0-5：旧任务与下游分析不受影响

- 应为真：历史任务的 `outputFile` 保持原值；已完成任务的 AI 总结/截图源解析继续可用。
- 不应为真：新命名格式破坏对历史任务或分析子任务的文件定位。

## Verification

- 运行级验证（真实下载）：需要运行中的 server + 真实 B 站视频，本会话无法执行。
