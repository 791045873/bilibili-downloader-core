# 2026-08-13 解析结果列表与 AI 总结任务分页及筛选 — 测试方向

关联计划：`docs/plans/2026-08-13-pagination-and-filter-plan.md`
关联需求：`docs/requirements/2026-08-13-pagination-and-filter.md`

验证命令：`pnpm typecheck`（零错误）+ `pnpm build`（零错误）+ DB 冒烟 + 下述手工回归。

## 1. 解析结果列表分页（`/parse-result/list`）

**应成立:**

- 投稿视频 / UGC 合集 / 收藏夹列表以服务端分页展示：默认第 1 页、每页 20 条；底部显示当前页/总页数、总条数、上一页/下一页、每页条数选择器（10/20/50）。
- 点击"下一页"/"上一页"后列表**整体替换**为新页数据（不再追加、不残留旧项）。
- 切换每页条数时回到第 1 页并按新条数加载。
- 单视频类型（`type=video`，分 P 或归属合集）不显示分页控件。

**不应成立:**

- 仍出现"加载更多"按钮；翻页时新旧页数据混合；单视频类型出现分页控件。

## 2. AI 总结任务分页

**应成立:**

- AI 总结任务页以分页展示：默认第 1 页、每页 20 条；底部显示当前页/总页数、总条数、上一页/下一页、每页条数选择器。
- 列表接口返回分页对象（items/page/pageSize/total/hasMore），前端按 total 计算总页数。
- 删除当前页最后一条且页码 > 1 时，页码回退一页并重新加载。

**不应成立:**

- 前端仍一次性拿到全量数组；翻页不触发服务端请求；删除后停在空页。

## 3. 状态筛选

**应成立:**

- 状态下拉可选：全部 / 待处理 / 处理中 / 完成 / 失败。
- 选择后列表只显示对应状态的记录，且回到第 1 页。

**不应成立:**

- 选择某状态后仍混入其它状态记录；筛选后停留在旧页码。

## 4. 标题搜索

**应成立:**

- 搜索框输入标题关键字提交后，列表只显示标题包含该关键字的记录（模糊匹配）。
- 标题为空的记录在搜索时不被匹配。
- 清空搜索条件可恢复全量。

**不应成立:**

- 搜索按 bvid/cid 匹配而非标题；搜索命中标题为空的记录。

## 5. 更新时间区间筛选

**应成立:**

- 起止日期输入（可只填其一）后，列表只显示 `updated_at` 落在 `[起始日 00:00:00, 结束日 23:59:59.999]` 闭区间内的记录。
- 起始与结束日期可单独留空表示不限。
- 区间筛选与状态、搜索按 AND 叠加。

**不应成立:**

- 只填起始日期却按单日精确匹配；区间为开区间导致边界记录丢失；多条件叠加变成 OR。

## 6. 非法参数拒绝

**应成立:**

- `GET /api/summary-tasks` 收到非法 `page`/`pageSize`（非正整数）、非法 `status`（不在允许集合）、非法 `updatedFrom`/`updatedTo`（不可解析的时间）时返回 HTTP 400，不返回部分结果、不崩 500。

**不应成立:**

- 非法参数被静默忽略、当作默认值，或导致查询返回错误数据 / 500。

## 7. 既有 AI 总结操作不回归

**应成立:**

- "查看原始 / 重新总结 / 删除 / 重新构建"按钮与弹窗行为不变。
- 刷新按钮仍只刷新当前页（不重置筛选条件、不跳页）。
- 列表响应 `items` 仍不含 `rawResponse`（原始返回仍仅按需查询）。

**不应成立:**

- 分页/筛选改动破坏删除、重新总结、查看原始、重新构建任一既有操作。

## 手工回归清单

- 场景 A：多页投稿视频列表 → 翻页替换、每页条数切换、单视频类型无分页。
- 场景 B：AI 总结任务 > 20 条 → 分页渲染、翻页、每页条数切换。
- 场景 C：状态下拉切换 → 结果过滤、回到第 1 页。
- 场景 D：标题关键字搜索 → 仅命中标题包含关键字的记录。
- 场景 E：起止日期筛选 → 仅命中区间内记录；只填起始/结束均正确。
- 场景 F：删除当前页最后一条 → 页码回退；刷新/删除/重新总结按当前条件重载。
- 场景 G：`pnpm typecheck`、`pnpm build` 零错误；DB 冒烟覆盖分页/筛选 SQL。

逻辑级（分页/筛选 SQL 正确性、参数校验、响应形状）通过代码检查 + DB 冒烟覆盖；运行级（真实 B 站视频多页列表、真实 AI 总结记录的界面筛选）留用户手动验证。

## 验证结论（2026-08-13）

- 方向 1–6（解析结果分页 / AI 总结分页 / 状态筛选 / 标题搜索 / 更新时间区间 / 既有操作不回归）：`passed`（逻辑级）——`pnpm typecheck`、`pnpm build` 通过；DB 冒烟 15/15 PASS 覆盖分页计数、状态精确过滤、标题模糊匹配、`%`/`_`/`\` LIKE 转义、空标题不匹配、更新时间闭区间、多条件 AND、翻页 hasMore；`grep` 确认源码无 `loadingMore`/`canLoadMore`/`loadMore` 残留。
- 方向 6（非法参数拒绝 400）：`passed`（逻辑级）——controller 局部 helper `toPositiveInt`/`parseAiSummaryStatus`/`parseOptionalIso` 抛出 `BadRequestException`，与下载列表既有模式一致；`pnpm typecheck`/`pnpm build` 通过。
- 手工回归清单场景 A–F（真实 B 站多页视频、真实 AI 总结记录的界面筛选、删除回退、HTTP 400 运行级）：`out of scope`（留用户手动验证）——需运行中的 server 与真实数据；逻辑级已由代码检查 + DB 冒烟覆盖，运行级行为不阻塞闭核。
