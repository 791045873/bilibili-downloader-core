# Docker 构建上下文误包含本地数据与环境文件

## 现象

修复前的镜像误包含本地下载、总结截图和测试素材，导致构建上下文和最终镜像异常膨胀；
服务端 `.env` 也可能随源码进入构建上下文。

## 风险

- 本地媒体和测试数据增加构建传输时间与镜像体积。
- `.env` 可能包含运行期密钥，不应进入构建上下文或镜像层。
- 大上下文会掩盖依赖安装和镜像层下载的真实耗时。

## 修复

根 `.dockerignore` 使用任意层级规则排除 `.env`、`.venv`、`downloads`、
`summaryDir`、`test_assets`、缓存和构建产物。

## 回归证明

构建日志中的 context 传输量应保持在源码实际所需范围；最终镜像不得包含上述本地目录或
环境文件。执行证据记录在
`docs/testing/2026/08-13-docker-fix-vision-proxy-testing.md`。
