# PM Notes - 视频解析页面优化

目标页面：哔哩哔哩下载器前端的视频解析页面。

目标组件：`packages/frontend/src/views/VideoDetail.vue`（用户口径：`videodetail.view`）。

用户提出的优化内容：

1. Video table header 的第一列文字表述有误，需要调整。
2. 将页面从"一次性展示所有 section"调整为"使用 section 选择器，一次展示一个 section"。section 选择器模块以胶囊按钮形式排布，展示所有 section。用户点击对应胶囊按钮选中该 section，页面仅显示该 section 下的内容。
3. 当点击"加入下载队列"时，不应当直接跳转到下载队列页面，应该仍然停留在当前页面。
4. 那些已经加入到下载队列的视频应当被禁止选中，因为不应该将同一份视频重复下载。
5. 将"解析选中"按钮调整为"解析当前页所有视频"按钮。因为在用户习惯中，一般都会全选所有视频后再点击"解析选中"。所以在该位置直接提供一个"一键解析所有视频"的按钮会更方便，更符合用户习惯。
6. 当用户点击"加入下载队列"按钮时，提供一个弹框，允许用户修改所要下载视频的存储目录。由于已通过 section 选择器限制了每次只展示一个 section，所有选中的视频都属于同一 section，不再存在跨 section 场景。
